# Блокнот официанта: как выложить на GitHub Pages

В папке всё готово. Ничего устанавливать на компьютер не нужно, всё делается в браузере.

## 1. Выложить на GitHub (10 минут, один раз)

1. Зайдите на github.com и войдите в аккаунт (если его нет, зарегистрируйтесь, это бесплатно).
2. Нажмите «+» вверху справа → «New repository».
3. Название: `waiter-notes` (можно любое, латиницей). Тип: Public. Нажмите «Create repository».
4. На открывшейся странице нажмите ссылку «uploading an existing file».
5. Распакуйте архив и перетащите в окно браузера ВСЕ файлы из папки (не саму папку): index.html, manifest.webmanifest, sw.js и три png.
6. Внизу нажмите «Commit changes».
7. Откройте «Settings» → слева «Pages». В поле «Branch» выберите `main`, рядом `/ (root)`, нажмите «Save».
8. Через 1–2 минуты вверху страницы Pages появится адрес вида `https://ваш-логин.github.io/waiter-notes/`. Это и есть ваше приложение.

## 2. Поставить на телефон

iPhone: откройте адрес именно в Safari. Нажмите «Поделиться» (квадрат со стрелкой) → «На экран “Домой”» → «Добавить».

Android: откройте адрес в Chrome. Нажмите ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Откройте приложение с иконки. Первый раз нужен интернет, дальше оно работает и без него.

## Важно знать

- Данные (заказы, время готовки блюд) хранятся только в памяти этого телефона. Приложение с главного экрана и страница в обычном браузере хранят данные отдельно, поэтому заказы из одного не появятся в другом. Если очистить данные сайтов или сменить телефон, записи пропадут.
- Репозиторий публичный: любой, у кого есть ссылка, может увидеть файлы (меню и код приложения). Заказов и личных данных там нет.
- Сигнал «блюдо готово» звучит, пока экран включён. Кнопка «Экран» вверху не даёт ему погаснуть. Когда телефон заблокирован, iPhone и Android усыпляют приложение, и сигнала не будет.

## Обновить приложение

Если пришлют новый index.html: откройте репозиторий → файл index.html → значок карандаша → вставьте новое содержимое → «Commit changes». Через минуту приложение обновится само при следующем запуске с интернетом.
